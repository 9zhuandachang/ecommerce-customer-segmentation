# E-commerce Customer Segmentation & 30-Day Repurchase Prediction

A machine learning pipeline and interactive dashboard for customer segmentation and repurchase prediction on the **UCI Online Retail II** dataset.

## Project Structure

```
project/
├── data/
│   ├── raw/                    # Place online_retail_II.xlsx here
│   └── processed/              # Generated by pipeline
├── models/                     # Saved model & segmentation pipelines
├── src/
│   ├── data_cleaning.py        # Data cleaning & audit
│   ├── features.py             # Feature engineering & snapshot builder
│   ├── segmentation.py         # K-Means clustering (k=3..6)
│   ├── modelling.py            # 6 model experiments + evaluation
│   └── train_pipeline.py       # Offline training orchestrator
├── app/
│   └── dashboard.py            # Streamlit dashboard (3 views)
├── demo_run.py                 # Synthetic data demo (no real dataset needed)
├── requirements.txt
└── README.md
```

## Real Dataset Workflow

1. **Download** the UCI Online Retail II dataset:
   https://archive.ics.uci.edu/dataset/502/online+retail+ii

2. **Place** `online_retail_II.xlsx` in `data/raw/`

3. **Train** the pipeline:
   ```bash
   python src/train_pipeline.py
   ```

4. **Launch** the dashboard:
   ```bash
   streamlit run app/dashboard.py
   ```

## ML Approach

### Customer Snapshots
For each cutoff date **t**, we compute:
- **Features (past 180 days):** recency, frequency, monetary value, AOV, product diversity, 30-day count, 90-day count
- **Label (next 30 days):** 1 if any qualifying purchase, else 0

### Segmentation
K-Means on RFM features with k = 3…6, selected by silhouette score.
Segments are named: **Champions**, **Loyal**, **At Risk**.

### Six Prediction Experiments
| # | Model |
|---|-------|
| 1 | Logistic Regression |
| 2 | LightGBM (GBDT) |
| 3 | Soft-voting Ensemble (w=0.25 LR) |
| 4 | Soft-voting Ensemble (w=0.50) |
| 5 | Soft-voting Ensemble (w=0.75 LR) |
| 6 | Dummy Baseline |

### Leakage Control
- Chronological train / validation / test splits
- Imputation, scaling and clustering fit on **training data only**

## Dashboard Views
1. **Overview** – KPI cards (customers scored, segments, avg score, model perf)
2. **Segment Profiles** – K selection chart, pie chart, scatter, stats table
3. **Customer Review** – Date picker, segment filter, top-N ranking, CSV export
4. **Model Comparison** – ROC-AUC / PR-AUC bar charts, full metrics table
