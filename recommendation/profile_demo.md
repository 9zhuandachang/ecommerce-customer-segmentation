# 购买习惯画像与推荐名单：一步步查看

> 本文件保留原研究界面步骤。当前前端已收敛为四个业务入口，不再提供实验版本及算法切换。实际使用请选择“画像与商品推荐”；本轮研究结果通过`outputs/profile_v2/report.md`查看。

本轮已完成画像、倾向预测、四组推荐比较、页面与导出。**默认仍为个人补货**：画像混合的推荐提升太小，未达到事先门槛。可以在同一页面切换查看画像如何影响名单。

## 打开

在PowerShell运行：

```powershell
Set-Location 'D:\桌面\AIS课件与workshop\pre2\main'
python -B -m recommendation.profile_experiment
python -m streamlit run app/dashboard.py
```

第一条Python命令核对现有完整产物，不会重新选型。浏览器打开终端显示的地址，通常为 `http://localhost:8501`。

## 演示：客户12348，2011-06-01

1. 左侧打开 **Product recommendations**，推荐实验版本选择 **购买习惯画像与混合推荐**。
2. 推荐日期选 **2011-06-01**，推荐客户ID选 **12348**。
3. 查看画像：此前180天有 **3次购买、2笔可比较订单**，历史重复比例 **0%**、前3商品集中度 **14.3%**。近期变化留空，因为需要至少4笔可比较订单。0%只表示这段可见记录中未重复，不代表今后不会重复。
4. 页面显示下一单条件重复比例预测约 **22.8%**。它回答“如果30天内有下一单，其中老商品可能占多少”，不是客户购买概率；只有两笔可比较记录，页面会显示“记录较少”。
5. 先查看 **纯个人补货**：第10件为 **21982**，以前买过。
6. 切换 **画像混合＋EASE**：补货权重约 **90.4%**、发现权重约 **9.6%**。前9件与纯补货相同，第10件换成此前未买的 **21212**。
7. 点击 **下载该客户画像与推荐名单**，导出同一份画像、权重和10件商品；文件不含下一单真实商品或是否命中。

这是一个展示名单确实会随权重变化的真实输入案例，按“名单变化且有至少两笔可比较订单”的首个客户选取，不用于证明整体提升。

## 怎样看比较结果

- 页面下方展开四组方案比较；原始五方案仍可在版本菜单切换。
- 验证期：纯补货NDCG@10 **0.3226**，最强画像混合（EASE）**0.3228**，差值仅 **0.00018**；客户抽样区间包含0，不能认定稳定提升。
- 三个固定混合在开发期都选到补货权重 **1**，所以其结果与纯补货一致。这是允许的边界解，没有为显示混合而强制添加未买商品。
- 倾向预测的验证MAE：历史比例 **0.2526**、岭回归 **0.2220**、小型LightGBM **0.2188**。倾向预测改善并不自动代表推荐改善。
- 9–11月答案在上一轮已查看，本轮固定后只复核，不根据复核改参数。

## 文件

| 文件 | 用途 |
|---|---|
| `profile_protocol.md` | 事先写入的公式、时间边界、搜索和选型规则 |
| `outputs/profile_v2/report.md` | 完整比较结果及限制 |
| `outputs/profile_v2/profiles.csv` | 页面六个月的17,021条安全画像与预测，无未来答案 |
| `outputs/profile_v2/validation_lists.csv`、`test_lists.csv` | 11种方法、共187,231份每人10件名单及权重，无未来答案 |
| `outputs/profile_v2/propensity_development_monthly.csv` | 三类倾向方法的五轮开发结果 |
| `outputs/profile_v2/hybrid_development_monthly.csv` | 每轮132个混合配置的完整结果 |
| `outputs/profile_v2/validation_groups.csv`、`test_groups.csv` | 按画像分组的逐月表现 |
| `outputs/profile_v2/locked_selection.json`、`model_bundle.joblib` | 冻结的默认选择、参数及可重算模型 |

`training_repeat_share_labels.csv`及`*_propensity_predictions.csv`是离线训练/核对资料，含真实答案，不进入页面和用户导出。
