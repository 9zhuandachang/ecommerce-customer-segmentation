# 业务范围与数据口径（阶段一）

## 目标与适用对象

当前前端包含独立的“数据导入”入口，以及客户分群、复购优先名单、高消费潜力、画像与商品推荐四项分析。模型比较、实验切换、版本哈希和验证过程不再展示；研究报告与审计仍保留在项目目录。业务CSV只导出页面可见信息及日期、客户和所选客户画像，不附带技术版本或未来答案。

使用者是客户关系管理或客户留存团队。当前支持四项分析：客户分群、未来30天复购评分、未来消费潜力排序，以及下一笔订单的Top10商品推荐。系统供人工查看、排序和导出名单，不自动决定或发送营销活动。

数据仅来自 UCI Online Retail II 的两份年度 CSV，覆盖一家英国零售商 2009 年 12 月 1 日至 2011 年 12 月 9 日的交易，包含批发客户。原始记录共 **1,067,371 条交易明细行**，不是 1,067,371 名客户。清洗后保留 776,579 条合格明细行，排除 290,792 行；每行的来源及主要排除原因见清洗审计。原始文件和来源哈希见 `data/raw/` 与 `data/processed/customer_snapshot_pipeline/run_manifest.json`。

| 统计单位 | 含义与用途 |
| --- | --- |
| 交易行 | 一个发票上的一个商品明细；原始和清洗行数按此统计。 |
| 发票 | 同一客户的同一合格发票；购买频次按不同的合格发票计数，同一发票的多条商品行只计一次。 |
| 客户 | 有可用 Customer ID 的唯一客户；ID 用于关联与导出，不作为预测特征。缺失 ID 的行无法进入客户级分析。 |
| 客户快照 | 一个客户在一个历史截止日期 `t` 的状态；同一客户可在多个日期出现。当前 18 个截止日期共有 54,040 条快照，不能当成 54,040 名独立客户。 |

## 合格购买与快照

“合格购买”指通过 `src/data_cleaning.py` 规则的正向商品交易：有效日期、发票、商品编码、客户 ID、数量和单价；不是取消发票、非正数量或单价、完全重复行或非商品条目。同一客户同一发票至少有一条合格商品行，才计一次合格发票。排除顺序、规则命中数和逐行原因见 `docs/customer_snapshot_pipeline.md` 及审计 CSV。该口径观察购买，不等于最终扣除退货后的净收入。

每月 1 日设截止时间 `t`。仅在 `[t-180 天, t)` 内至少有一次合格购买的可识别客户属于本项目的“现有客户”，并生成快照。最近一次购买间隔、发票频次、消费金额、平均订单金额、商品多样性、近 30/90 天发票次数仅用 `t` 以前的记录。`customer_history_days` 可用更早的历史求首次购买日期，其含义单独记录。标签 `repurchase_30d=1` 表示 `[t, t+30 天)` 至少有一次合格购买，否则为 0；仅保留未来 30 天数据完整的日期。训练、验证、测试按日期先后分区，具体边界以 `cutoff_schedule.csv` 为准。

## 界面和导出

当前页面只上传购买明细并选择分析日期，系统自动排除当天及之后的交易，再为此前180天有购买的客户生成快照。四个菜单共用本次生成的日期和客户集合，不读取固定月份名单。支持群体或客户筛选、名单长度设置和业务CSV导出。字段模板和完整步骤见[上传数据使用说明](上传数据使用说明.md)。12月演示快照没有未来标签，不进入原训练或评估总表。

| 字段 | 含义 |
| --- | --- |
| 客户 ID | 客户关联标识，不作为模型特征。 |
| 客户群体 | K-means归属：群1较久未购、群2近期高频、群3近期低客单、群4近期高客单。 |
| 复购评分 | XGBoost对未来30天复购的排序评分；未经新版概率校准。 |
| 优先名次 | 当前筛选结果内按复购评分降序的名次，从1开始。 |
| 潜力排名 | 本批上传客户整体的消费潜力名次，筛选后保留原名次。 |
| 分析日期 | 用户选择的截止日期，支持2011-09-01至2011-12-01之间任意一天（含首尾）。 |

复购CSV还附带最近购买间隔、订单数、历史消费额和客单价。上传后调用冻结的K-means、XGBoost及两步LightGBM重新计算，不读取客户旧名单。默认商品推荐仍为个人重复购买规则，使用冻结商品库与同分顺序；候选模型及画像混合的比较保留在离线报告，前端不提供版本或算法切换。导出只含可见业务字段、分析日期及必要客户画像，不附带未来答案、模型版本或原始推荐分数。

画像按180天内的购买时刻统计：同一客户同一时间的发票合并成一次购买、商品去重，首次可见购买只建立参照。后续订单的重复商品比例取平均；近期变化至少需要4笔可比较订单。未买商品仅指该客户截点前180天没有买过。倾向模型只学习有下一单且30天答案已完整观察的历史样本；没有下一单不标成比例0。新方案和实测边界见[画像与推荐结果](../recommendation/outputs/profile_v2/report.md)。

## 边界与当前进度

本数据没有营销触达和干预结果，无法推断活动增量、营销 ROI 或因果效果。单一零售商、缺失客户 ID、批发交易及季节变化限制覆盖和推广性。当前版本不包含营销发送、实时系统接入、新客户评分、仪表板内训练或自动重训。商品推荐已实现按时间对比、Top10名单及导出；默认方案偏向重复购买，对未买过商品的召回较弱，且没有实时库存信息。

上一级目录的英文 PPT 和中文 proposal 是 **2026 年 9 月的计划版本**，与当前进度不同。新阶段四选择 K-means 四群，新阶段五选择 14 项特征的 XGBoost，两者已接入统一历史回放。2011 年 9–11 月的回顾性 AP 为 0.6201，基础八项逻辑回归为 0.6064；这些月份不是新独立测试。PPT 中仍属计划或早期原型的描述需要在最终展示前更新；讲解以 PPT 中的内容和示例为基础，并准确说明现有结果与局限。
