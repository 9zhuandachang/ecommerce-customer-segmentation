# 阶段五：复购模型重新对比

本实验在同一批客户月快照上比较四种模型、三组特征。训练期为 2010-06 至 2011-05，正式验证期为 2011-06 至 2011-08；测试标签未参与本实验。
此前项目已查看过这批历史数据，因此结果属于回顾性比较，不是新的独立验证。

选择规则：先在训练期三个向前月份为每个组合选复杂度，再按正式验证期 AP 选模型；候选的向前平均 AP 和验证期 Top 20% 精确率不能低于基础八项 LR。

**选定：base_8_plus_trend_and_rhythm / XGBoost，复杂度参数 2。**
入选模型完整参数：`{"n_estimators": 300, "learning_rate": 0.05, "max_depth": 2, "min_child_weight": 10, "reg_lambda": 3, "subsample": 0.9, "colsample_bytree": 1, "tree_method": "hist", "grow_policy": "depthwise", "random_state": 42}`。
验证 AP=0.6009，Top 20% 精确率=0.6064；验证期平均评分=0.2595，实际复购率=0.2672。

事后按客户成组重抽样检查 AP 差值（不参与选模）：
| 对比对象 | 观察到的 AP 差 | 95% 重抽样区间 |
| --- | ---: | ---: |
| base_8_plus_trend_and_rhythm / LightGBM | +0.0013 | [-0.0014, +0.0036] |
| base_8 / LR | +0.0142 | [+0.0089, +0.0190] |
该区间只反映这些验证客户的重抽样波动；模型是在同一验证期选出的，且只有三个月，因此它不是未来表现的置信保证。

逐月结果见 `monthly_validation.csv`；每轮向前结果见 `forward_folds.csv`；所有验证评分见 `validation_predictions.csv`。入选模型仅用训练期拟合，保存为 `selected_model.joblib`。此实验尚未替换阶段六或仪表板模型。

只凭这些历史指标，不能推断真实营销增量或未来新数据表现。
