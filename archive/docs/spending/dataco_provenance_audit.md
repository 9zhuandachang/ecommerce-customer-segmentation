# DataCo source availability audit (amount model not run)

`dataco_protocol.md` was written before downloading and viewing this document. The original author's [Mendeley Data v 5](https://data.mendeley.com/datasets/8gx2fvg2k6/5) page states that the data comes from DataCo Global; the compressed package SHA- 256 of the public Kaggle image is `96f3a04ce2e5384248b393f20221ab9d16b33f94b9af72439170e8e220d7b0b1`, which contains `DataCoSupplyChainDataset.csv` ( 180,519 line), field descriptions and log files. The original image is only in the system temporary directory, and the customer row or any personal information is not stored in the warehouse. When reading, only select the order date, status, order and customer ID, product and amount fields.

In the source check before model and future amount tag calculation, all orders cover 2015-01-01 to 2018-01-31 for 1,127 days, and the number of unique orders per day means 58.34, standard deviation 4.63, minimum 47, maximum 69; the unique number of orders aggregated by week is 9,367 – 9,430, almost perfectly even. The daily average of orders with status `COMPLETE` or `CLOSED` is 25.70 and the standard deviation is 4.30. Check other fields: source customer 20,652, order 65,752, row ID 180,519; rows with qualified status and positive amount/quantity include 79,107, involving 14,543 customers and 28,965 orders. There is no conflict between the customer ID and the order customer ID, and there is no duplication of row IDs.

These time series patterns **do not prove that the data is synthetic** nor that it preserves unsampled natural sales fluctuations. Since the goal of this project clearly requires true and explainable independent transaction verification, this file is not currently used for final model acceptance or system access; `dataco_protocol.md` is only retained as a record of pre-download rules and source screening. This decision is based on the source time structure and is not based on any future amount projections.
