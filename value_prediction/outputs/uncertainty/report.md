# 开发确认期客户成组不确定性

2011 年 6–8 月共有 8,146 条客户月快照、3,093 名客户。按客户重抽样 500 次，随机种子 42，所有方法共享每次抽到的客户。
这是固定三个月内的客户抽样区间，不包含未来月份变化，也不是新的独立测试。

| 比较 | 点估计 | 95% 客户抽样区间 |
| --- | ---: | ---: |
| 去年同期直接模型整体 MAE 降幅 | +12.64% | [+9.57%, +16.83%] |
| 去年同期直接模型 Top20 覆盖提升（百分点） | +1.95 个百分点 | [+0.67 个百分点, +3.20 个百分点] |
| 购买者滞后校准两阶段模型整体 MAE 降幅 | +6.45% | [+3.24%, +10.83%] |
| 购买者滞后校准两阶段模型 Top20 覆盖提升（百分点） | +1.81 个百分点 | [+0.41 个百分点, +2.61 个百分点] |
| 去年同期条件中位数对历史订单均价的购买者 MAE 降幅 | +15.39% | [+10.59%, +21.99%] |

区间只检查这些已查看月份里，客户构成变化会让结论波动多少。即使整个区间高于零，也不能证明新月份或另一家商家会达到原挑战标准。
