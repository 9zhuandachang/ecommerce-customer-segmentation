# DataCo 来源可用性审计（未运行金额模型）

`dataco_protocol.md` 写于下载和查看本文件之前。原作者的 [Mendeley Data v5](https://data.mendeley.com/datasets/8gx2fvg2k6/5) 页面称资料来自 DataCo Global；公开 Kaggle 镜像的压缩包 SHA-256 为 `96f3a04ce2e5384248b393f20221ab9d16b33f94b9af72439170e8e220d7b0b1`，内含 `DataCoSupplyChainDataset.csv`（180,519 行）、字段说明和日志文件。原始镜像只在系统临时目录，仓库未存入客户行或任何个人信息。读取时只选订单日期、状态、订单及客户 ID、商品和金额字段。

在模型和未来金额标签计算前的来源检查中，所有订单覆盖 2015-01-01 至 2018-01-31 的 1,127 天，每日唯一订单数平均 58.34、标准差 4.63、最少 47、最多 69；按星期汇总的唯一订单数为 9,367–9,430，几乎完全均匀。状态为 `COMPLETE` 或 `CLOSED` 的订单每日平均 25.70、标准差 4.30。其他字段核对：源客户 20,652、订单 65,752、行 ID 180,519 个；合格状态与正金额/数量的行有 79,107，涉及 14,543 名客户、28,965 笔订单。客户 ID 与订单客户 ID 无冲突，行 ID 无重复。

这些时序形态**不能证明数据是合成的**，也不能证明它保留了未抽样的自然销售波动。由于本项目的目标明确要求真实、可解释的独立交易验证，当前不把该文件用于最终模型验收或系统接入；`dataco_protocol.md` 仅保留为下载前规则和来源筛选记录。这个决定基于来源时间结构，不基于任何未来金额预测结果。
