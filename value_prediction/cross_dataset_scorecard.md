计算：`整体 MAE 改善 = (基线 MAE - 模型 MAE) / 基线 MAE`；购买者 MAE 同理；`Top20 消费覆盖提升 = 模型覆盖率 - 基线覆盖率`。这里的“单月 MAE 胜出”只计严格低于基线的月份，**不能代替**同时要求单月 Top20 不差的原挑战目标。合并总额偏差可能抵消不同月份的高估和低估，因此必须与最后一列一起看。

数据出处：原商家开发期为 `outputs/optimization/development_comparison.csv` 与 `monthly_development.csv`；原商家回顾期为 `outputs/retrospective_check/overall_metrics.csv` 与 `monthly_metrics.csv`；四组外部数据分别为 `outputs/two_year_validation/`、`outputs/jewelry_validation/`、`outputs/amazon_validation/`、`outputs/cdnow_validation/` 中的 `pooled_test_metrics.csv` 与 `monthly_metrics.csv`。各目录的 `manifest.json` 与相应协议记录来源、数据处理及测试时段。CDNOW 是美元计价的历史 CD 零售数据，商品 ID 不可用，按事前规则剔除了 80 笔零金额交易。原商家回顾期已经看过，不能再用于挑选方案；外部商家测试只检验方法可迁移性，不能冒充原商家的未来独立验收。

## 研究判断

1. 当前直接金额模型对优先客户排序有较一致的帮助，但整体 MAE 优势并未跨商家稳定出现，购买者误差也未稳定改善。CDNOW 的 MAE 与名单覆盖均优于基线，但购买者 MAE 反而高 6.91%。
2. 珠宝数据的强整体 MAE 优势不能代表普遍效果：其基线总额高估接近 100%，而模型单月总额偏差仍大幅波动。Amazon 数据上的整体 MAE 则与基线几乎相同。
3. 原商家未来 30 天消费额的点估计尚未达到预先锁定的多指标挑战目标。没有新同商家真实交易时，现有月份只能用于诊断和开发，不能生成一次新的独立验收。
4. 若用途是筛选优先客户，可单独研究名单排序和预测区间；不可把它们解释为个人金额准确，也不可据此把金额预测接入正式仪表板。
