# DataCo 真实交易：双输出方法的跨商家固定检验

记录于下载完整交易文件、查看本数据的客户级未来标签或模型结果之前。原始数据由 DataCo 研究团队发布于 [Mendeley Data v5](https://data.mendeley.com/datasets/8gx2fvg2k6/5)（DOI 10.17632/8gx2fvg2k6.5，CC BY 4.0）。若官方文件无法直接通过 API 获取，可下载 Kaggle 的公开镜像；需保留下载 URL、压缩包 SHA-256、文件名、原始行数和字段核对。原始文件只留本机系统临时目录，仓库不保存原始客户行、个人信息或客户级外部预测。只读取完成本实验所需的客户 ID、订单 ID、行 ID、订单日期、商品 ID、数量、折扣后行金额、订单状态等字段，不读取姓名、邮箱、地址或密码。

## 来源和窗口

- 合格交易行须有客户 ID、订单 ID、商品 ID、有效订单日期、正数量、正的 `Order Item Total`，且最终订单状态为 `COMPLETE` 或 `CLOSED`（大小写不敏感）。其他状态及缺失、非正金额行按互斥主要原因排除并计数。行金额按源数值四舍五入到分，记录舍入前后总金额；同一订单的多条商品行分别保留，发票频次以唯一订单 ID 计。若同一订单 ID 对应多个客户、或同一行 ID 冲突，停止并审计。`Order Item Total` 是折扣后行金额；不把 `Sales per customer` 等未来汇总列当输入。
- 从合格交易的实际最早日和最晚日自动生成每月 1 日截点，输入窗口 `[t-180d,t)`，未来金额与是否购买标签为 `[t,t+30d)`。仅保留 180 天观察和 30 天标签都完整的月份；如果覆盖不连续、完整截点不足 12 个或最后一个标签结束超出文件末日，停止并只报告可行性。不按模型结果选择日期。
- 按时间顺序，最后 3 个完整截点为**锁定测试**，之前 3 个为开发确认，其余作更早历史。每个评分截点只使用 `训练截点+30天<=评分截点` 的已成熟标签。若锁定测试任一月少于 1,000 个有前 180 天交易的客户快照或少于 100 名未来购买者，只报告可行性，不判模型。

## 固定预测器和两个业务输出

1. **全客户预期金额**：复用阶段五 A 组的 8 特征 LightGBM 复购分类器（15 叶、64 树、学习率 0.05、类平衡、种子 42），每折在较早成熟月份拟合，保留最近三个成熟月作独立校准队列，仅用其中最近两个月对冻结分类器作 sigmoid 概率校准。购买后金额均值另用 20 项截点前特征的 Gamma LightGBM，在全部成熟历史购买者上拟合（120 树、0.05、15 叶、种子 42）。预期金额等于校准购买概率乘条件均值，不使用真实未来购买状态。与相同客户的历史 180 天金额 `/6`、20 特征直接 Tweedie（120 树、0.05、15 叶、幂 1.5、种子 42）比较。
2. **若购买后的金额**：20 特征 LightGBM L1 条件中位数，仅在已成熟历史购买者上拟合（120 树、0.05、15 叶、种子 42）。这是条件情景预测，不能冒充所有客户的无条件金额；只对未来确实购买者评估，并同时与 `过去180天金额/6` 及 `过去180天平均订单金额` 对照。预测时不知道谁会购买。

## 事先固定的报告与判据

- 对每月和锁定三月合并报告：全客户预期金额的 MAE、购买者 MAE、每月各自选择的 Top20 实际消费额覆盖、总额偏差和 Top20 群体偏差；购买概率的 AP、Brier、预测人数偏差；条件中位数的购买者 MAE 与金额偏差。报告三个测试月的逐月误差和偏差，不能用合并抵消代替稳定性。保存来源、清洗排除、金额与快照标签核对、每折最新训练/校准标签截止和脚本/协议哈希。
- **预期金额推进条件**：相对历史 180 天金额基线，合并 MAE 至少低 10%，Top20 覆盖至少高 3 个百分点，合并总额偏差在 ±5% 内，Top20 群体偏差在 ±10% 内；三个测试月 MAE 和 Top20 都不得差于基线。
- **条件金额推进条件**：合并的购买者 MAE 至少比两个固定对照都低 10%，三个测试月中至少两个都不差于两个对照。该条件单独评估，绝不替代原强化目标中的“无条件预计金额在实际购买者上的 MAE”。原强化目标的购买者 MAE 至少低 5% 也原样列出。
- 全部条件达到只说明两个方法在这个独立商家有迁移证据。该数据是全球供应链销售，可能同时包含企业或实体渠道，金额单位与原英国在线商家不能混算；无论通过与否，都不能代替原商家未来新月份的同店验收。没有同店可信验收前，不把消费额预测接入仪表板，不宣称确定的营销收益。
